### 💫 About Me

I am a **Full Stack Developer** specializing in the **MERN Stack (MongoDB, Express.js, React.js, Node.js)** and **TypeScript**, with hands-on experience building production-ready web applications, RESTful APIs, and scalable database architectures.

- 💼 **Real-World Systems:** Experienced in developing enterprise-grade applications including an **HRMS & Payroll Management System** (using TypeScript, Prisma ORM, PostgreSQL & Supabase), full-stack **E-Commerce platforms**, and a **Borrower Intelligence (BI) Rating Engine**.
- 🔐 **Security & Architecture:** Skilled in implementing JWT authentication, role-based access control, Zod schema validation, rate-limiting, input sanitization, and third-party payment integrations like **Razorpay**.
